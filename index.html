Agentic Text-to-SQL with Table-Level Retrieval for Protective Relay Settings

Gustavo L. B. Pereira, João Pedro G. Fernandes, João Pedro A. F. Matos, Vinícius A. Aguiar, Sávio S. T. de Oliveira, Anderson S. Soares

Institute of Informatics, Federal University of Goiás (UFG) · Center of Excellence in Artificial Intelligence (CEIA)

PDF (accepted manuscript) Version of Record (Springer)

Abstract

Protective relay configuration data is critical for power system operations, yet it remains locked in heterogeneous PDF manuals from multiple manufacturers with non-standardized formats and low-semantic parameter names. We propose an agentic Text-to-SQL system for natural-language access to relay configuration parameters, built on a structured relational database extracted from PDF tables and equipped with a ReAct-style agent that combines semantic retrieval with SQL execution. We systematically compare two retrieval strategies: Section-Level Retrieval (SLR), which indexes full document sections, and Table-Level Retrieval (TLR), which indexes per-table LLM-generated descriptions. On a domain-specific evaluation set of 112 questions over relay manuals from seven manufacturers, TLR achieves mean factual correctness of [0.87; 0.91], outperforming SLR with the same backbone at lower token cost and latency, with the advantage consistent across both backbone models evaluated. The results indicate that retrieval granularity and backbone capability each contribute separately to accuracy and efficiency, with the strongest configuration combining table-level retrieval and the more capable backbone.
